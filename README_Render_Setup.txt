1. Перейди на https://render.com
2. Натисни 'New + → Web Service → Upload from ZIP'
3. Завантаж архів 'einaya_nacia_bot.zip'
4. Build Command: pip install -r requirements.txt
5. Start Command: bash start.sh
6. Додай змінну середовища:
   KEY: API_TOKEN
   VALUE: <сюди токен від BotFather>
7. Натисни 'Deploy' — бот запуститься автоматично та працюватиме 24/7.
